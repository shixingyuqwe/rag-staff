## 常见问题排查

如果测试结果不理想，检查以下方面：

1. **检索不到相关内容**
   - 检查文档是否成功上传（`GET /api/kb/documents`）
   - 检查 chunk 数量是否合理
   - 尝试调整 `top_k` 参数

2. **LLM 胡编答案**
   - 检查 prompt 是否包含"不要编造"的约束
   - 检查 sources 是否为空
   - 降低 temperature 参数

3. **检索到了但不相关**
   - chunk_size 可能太大或太小
   - 问题表述和制度文本差异太大
   - Embedding 模型不适合当前领域
